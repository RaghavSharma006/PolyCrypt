How Polynomial Interpolation Powers Multi-Key Security

PolyCrypt leverages Lagrange polynomial interpolation to securely associate multiple secret messages with different secret keys.

1️⃣

Secret Point Construction

Each secret message is converted into a numeric representation yi. The corresponding secret key is treated as the coordinate xi, forming a unique point:

(xi, yi)
Every key–message pair becomes a point on a polynomial.
2️⃣

Polynomial Generation

Using all generated points, PolyCrypt constructs a unique polynomial P(x) of degree N - 1 that passes exactly through every point:

(x1, y1), (x2, y2), …, (xN, yN)
This single polynomial mathematically encodes every hidden message.
3️⃣

Key-Specific Decryption

During decryption, the provided key is used as the input x to evaluate the polynomial:

P(xi) = yi
If the key is valid, the corresponding message is recovered. Any other value produces an unrelated result, preventing access to the hidden messages associated with other keys.
